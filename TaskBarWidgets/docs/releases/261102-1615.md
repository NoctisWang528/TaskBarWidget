# 卡片动效与绘制改进

## 用户可见变更

- 改善快捷卡片及设备、播放源菜单的开合动画，连续点击和快速反向切换时衔接更自然。
- 修复媒体封面切换时淡化效果被新封面遮挡的问题。
- 调整流量热力图光晕的绘制隔离，减少与媒体卡片同时刷新时的画面干扰。
- 改善动画期间的窗口收起、重新打开，以及系统减少动画、高对比度和 DPI 变化时的处理。

## 升级注意事项

- 使用应用内更新时，确认后再安装；已有个人配置与历史数据继续保留。
- 手动升级请先备份 `Data` 目录、退出旧版，再完整解压程序文件。不要只替换主程序。

## 运行要求

- Windows 11 x64。
- .NET 8 Desktop Runtime x64，使用最新 8.0 补丁。
- Windows App Runtime 2.5.1 x64 或兼容的更新 2.x。
- 程序会检查运行依赖，缺失时提供下载入口，不会自动安装。
