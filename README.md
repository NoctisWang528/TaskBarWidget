# TaskBarWidget

A workspace containing three independent Windows taskbar applications, managed in one Git repository.

| Directory | Upstream project | Main stack |
| --- | --- | --- |
| [TrafficMonitor](TrafficMonitor/) | [zhongyang219/TrafficMonitor](https://github.com/zhongyang219/TrafficMonitor) | C++20, MFC |
| [TaskbarLyrics](TaskbarLyrics/) | [ANYNC/TaskbarLyrics](https://github.com/ANYNC/TaskbarLyrics) | .NET 8, WPF, WebView2 |
| [AF-Media-Bar](AF-Media-Bar/) | [Fervent-Tempo/AF-Media-Bar](https://github.com/Fervent-Tempo/AF-Media-Bar) | .NET 10, WPF |

Each project retains its documentation and license. Follow [AGENTS.md](AGENTS.md) and the relevant project guide for development. Build and run applications separately; this workspace does not yet combine their functionality.
