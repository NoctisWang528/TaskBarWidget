# AF Media Bar

## Language

**媒体来源**：用户选择查看播放信息和歌词的播放器来源。同一网易云来源可以同时具有 SMTC 与内存两种信息通道。
_Avoid_: 用“SMTC 会话”泛指所有媒体来源。

**SMTC 通道**：播放器向 Windows 发布的媒体会话，可提供媒体信息及播放器支持的控制能力。
_Avoid_: 将一个通道等同于完整的媒体来源。

**内存通道**：读取播放器进程获得播放信息的通道，不以存在 SMTC 会话为前提；曲目详情可以结合播放器本地元数据获取。

**网易云音乐来源**：向用户呈现的单个网易云音乐来源，以内存信息为主、SMTC 为补充；通道差异不构成两个可选来源。
