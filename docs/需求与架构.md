# 当前需求与架构

更新：2026-10-16。本文是当前约定；历史讨论中的冲突方案不再生效。

## 产品范围

以 TrafficMonitor 原生任务栏和硬件监测为基础，整合 TaskbarLyrics 歌词与媒体能力、AF-Media-Bar 音频控制。仅针对 Windows 11。三个原项目是本地忽略、不跟踪的只读参考目录，不随 GitHub 仓库或发布包分发。产品源代码、依赖、构建与测试均在 `TaskBarWidgets/`，移走参考目录后仍须能构建。

保留可定制的显示内容、字体、颜色和布局；移除桌面主窗口及皮肤、监测阈值通知、外部插件加载和插件管理页。只内置原先使用的 Battery、PowerMon、WeatherPro，保留显示项标识及旧配置，选项放进硬件设置。

## 用户行为

- QQ／网易云音乐播放时显示歌词及已有逐字、翻译、过渡效果；暂停／停止恢复监测。
- 浏览器媒体播放时显示曲目信息与控制，不触发歌词查询。
- 滚轮可手动切换监测／媒体，到下一次有效播放状态或来源变化恢复自动；换曲和进度更新不重置。
- 左键打开卡片组，右键打开应用菜单，任务栏悬停不弹出详情。
- 普通卡自上而下为天气、流量、输入输出设备、媒体；天气卡默认位于顶部且可关闭，四卡可独立启停并拖动排序。更新就绪时在右侧增加独立窄提示卡，不参与普通卡排序。固定等宽、透明间隔，支持系统材质与减少动画偏好。设备通过浮动列表选择，不扩展卡片。
- 热力图显示最近12个自然周每日上传加下载，按窗口内日峰值分级并显示峰值；区分无记录、零流量和未来日期，方格为正方形并有适度泛光。
- 设备输入与输出分别支持选择、音量与静音。同步默认通信设备在音频设置中配置，默认开启，仅影响下一次主动设备切换。
- 模块池与组合条决定任务栏内容，单行开关控制一条／上下两条。双行上下项目共用列宽与间距，保留各行顺序；独占双行项目占完整列，单侧普通尾项仍留在所选半行，预览与原生布局采用同一规则。点击模块打开右侧属性抽屉；拖回池不丢弃标签、颜色。复选框保留原生内边距。
- 卡片仅在实际外部点击、Esc、入口切换或进入设置时收起，不因焦点／前台变化自动关闭。音频操作独立有界排队，静音不附带音量写入，操作读回不得被迟到状态覆盖。

## 三个内部进程，一个产品入口

| 组件 | 职责与技术 |
| --- | --- |
| Native/ | C++20／MFC：生命周期、硬件与流量、唯一任务栏窗口、DirectComposition 与窗口输入；WebView2 保留歌词渲染 |
| Media/ | .NET8：无界面调度器、SMTC、歌词核心、音频设备、设置持久化及服务适配；保留 WPF 依赖但不显示旧设置或卡片 |
| UI/ | .NET8／WinUI3／Windows App SDK2.5.1：所有可见设置、模块编辑、四张快捷卡片与可选更新提示卡 |

用户只启动根目录 `TaskBarWidgets.exe`，服务和界面随父进程退出。通信使用当前用户限定的本地管道、版本化消息、容量上限与请求关联；协议见 [IPC.md](../TaskBarWidgets/IPC.md)。天气凭据留在本地配置，不发送到界面或仓库。

原生设置是共用任务栏字体、背景色、不透明度的唯一来源。模块按稳定 ID 保存顺序和所在行；保留旧布局读取兼容。硬件访问仍需要管理员权限；窗口内模块拖动使用指针捕获，避免高权限 WinUI 系统拖放的已知限制。

## 构建与交付

用 `TaskBarWidgets/scripts/build.ps1` 构建完整硬件版，默认输出 `artifacts/builds/yyyyMMdd-HHmmss/`，发布版本使用构建时刻的 `yymmdd-hhmm`。包内包括 Native、Media、UI 及 Anti 996／第三方许可声明；`build-info.json` 记录构建信息，`artifacts/latest-build.txt` 指向最近成功的完整构建。正式包必须包含本次生成的 WinUI PRI/XBF，且哈希一致。发布 ZIP 不含本地用户配置、历史、凭据、备份与检查日志／图片。

保留配置和流量历史，迁移先备份并核对。用户已允许新包验证后删除紧邻上一版；运行中、锁定、越界或含链接的目录拒绝清理。不得停止／替换原日用安装，不修改全局游戏覆盖层设置。

构建不自动启动主程序。真实交互、混合 DPI、Explorer 重启和音频操作仍需桌面验收。构造测试、屏幕外模板加载和发布完整性检查的范围必须分别说明；当前证据及未完成验收见 [ACCEPTANCE.md](../TaskBarWidgets/ACCEPTANCE.md)。
