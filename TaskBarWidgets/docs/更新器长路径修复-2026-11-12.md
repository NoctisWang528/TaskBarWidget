# 更新器长路径修复与本地交付

## 原因与修复

日常安装从 261111-0820 更新正式版 261112-1822 时，两次在桥接阶段报 `Cannot copy backup/program file`，并正常回滚。桥接暂存仅完成前 26 个文件；首个未完成许可证的临时目标路径长 263 字符。旧 Win32 文件操作没有使用扩展路径。

更新器增加仅供文件 API 使用的本地绝对路径转换，覆盖读取、哈希、属性、复制、临时替换和回滚；逻辑路径、清单、作业、相对路径白名单与重解析点限制保持原语义。复制失败现在附带目标文件名与 Win32 错误码。没有修改系统长路径策略。

隔离测试增加超过 MAX_PATH 的许可证成功安装及健康失败回滚用例；测试宿主以非 Shell 的 asInvoker 方式启动，避免 ShellExecute 发起意外提权。
