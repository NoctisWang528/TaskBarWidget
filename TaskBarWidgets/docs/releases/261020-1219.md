# TaskBarWidgets 261020-1219

Windows 11 x64。卡片弹出改为启动预热 + 首帧门控，目标是消除首次打开的卡顿和白色闪屏。

- UI 进程在管道连通约 300 ms 后通过既有 `getMediaSettings` 读取快捷卡片配置，按启用的卡片顺序、列、字体和资源模式分批创建窗口、测量高度、以零透明度渲染一帧后立即隐藏；不初始化歌词渲染器，也不请求流量、天气或音频数据。
- 预热失败或配置读取失败时静默放弃，点击仍走原有按需创建路径，不影响功能。
- 卡片显示前先把根视觉 `Opacity` 置 0 并复位偏移，`AppWindow.Show(false)` 后等待一次 `CompositionTarget.Rendering` 才启动原有 150 ms 淡入；门控有 250 ms 超时保护，隐藏与重开的动画世代校验保持不变。
- 卡片内容区使用已加载的主题资源 `CardBackgroundFillColorDefaultBrush` 填充，主题切换自动跟随；Mica 仍只出现在卡片外侧，首帧时序异常时也不会露出纯白客户区。
- 新增 `UI/card-timing.log` 阶段计时：`positioned`、`shown`、`activated`、`first-frame`（含排队等待与首帧总耗时），仅在明显排队时记录 `queued`；日志有界，不记录曲名、歌词、路径或凭据。

验证：完整硬件 Release 构建 `20261020-121923`、版本 `261020-1219`；原生、Core、Media、Web 自动验证与 WinUI 屏外模板探针通过。探针覆盖预热卡片集合跟随媒体设置、预热渲染后不残留可见窗口、隐藏态几何不变、首帧前透明度为 0、淡入交接到首帧之后、隐藏中途重开和销毁竞态。真实 Mica、混合 DPI、Explorer 交互与连续开合耗时仍由用户桌面验收。
