# Application icon

`app-icon.png` is the original transparent image generated for TaskBarWidgets through the built-in ChatGPT `imagegen` tool. `app-icon.ico` is its Windows format conversion with 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel variants. No upstream project's logo is used as the product icon.

The icon is compiled into the native application, media service and WinUI frontend; the settings window uses the same ICO.

Generation prompt:

> Create a polished original Windows 11 desktop app icon for TaskBarWidgets, a lightweight taskbar monitor combining live system stats, music lyrics, and audio controls. One single icon, square 1024x1024 canvas, transparent outer background. Center an elegant compact rounded-square indigo-blue tile occupying about 84% of canvas with restrained Fluent-style soft dimensional shading. Inside the tile: an extremely clear minimal white horizontal taskbar motif near the lower third and three simple rounded vertical cyan-to-white bars of varying heights rising from that bar, one small flowing pulse bend visually integrating monitoring and music rhythm. Bold simple geometry, generous negative space, recognizable at 16 and 32 pixels, premium modern native Windows utility, crisp contours, no letters, no words, no numbers, no Microsoft or other existing brand logos, no busy texture, no neon spill outside the tile, no surrounding presentation mockup, no multi-image grid. Transparent outside the icon, not a checkerboard pattern.
