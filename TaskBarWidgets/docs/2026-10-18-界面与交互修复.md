# 界面、媒体交互与便携交付

本轮范围：修复媒体模式任务栏入口偶发失效、设置深色主题、热力图方形底层、设备卡片留白和登录启动；媒体卡片中加入同步歌词，并交付个人 build 与干净 release。

## 行为

- 普通任务栏点击由原生窗口管理完整手势，显示模式变化不丢失释放。封面不再依赖旧控制面板开关；浏览器播放按钮保持独立动作。同一手势只切换一次面板，诊断日志使用有界编号，不加入曲名或歌词。
- 媒体卡片在曲目信息与播放控件之间显示歌词，共享歌词解析、时间轴、字体及动画。空间不足时单行，暂停保留当前句；无歌词、浏览器或断连清空。隐藏不消费渲染帧，重新打开恢复当前快照。
- 设置主题施加到根节点，使用动态主题资源，覆盖抽屉、拖动浮影、菜单及标题栏。主题预览不销毁尚未完成的编辑。任务栏预览忠实显示用户自定义颜色。
- 热力图采用圆角 Alpha 遮罩的独立发光层，不再叠加矩形实心底色；仍按最近十二周峰值分级。高对比度不发光。
- 音频设备卡片按内容测量高度，空状态行折叠，错误状态变化重新排布卡片。选择设备仍为独立浮动列表。
- 登录启动使用当前用户交互式、最高权限计划任务，设置工作目录及登录延迟。注册失败、旧路径与旧 Run 项明确显示；修复先验证新任务再清理旧项。构建和设置读取不修改系统启动项。

## 交付约束

使用同一次硬件版完整构建，台北时间版本 `yymmdd-hhmm`。`artifacts/deliveries/<版本>/build` 为个人便携目录；`release` 包含干净目录、ZIP 和 SHA256。个人配置、天气凭据、流量历史、媒体设置、歌词映射及偏移仅进入个人目录；数据库通过一致性备份迁移。详见 [便携与分发包](便携与分发包.md)。

实现阶段不启动正常产品、不覆盖运行实例、不自动注册启动项。用户随后接受构建 `261018-1213`，授权将两轮界面及设置改动一起提交、推送并发布干净 ZIP；个人包仅保留在本机。原始参考目录不参与构建。

## 验证重点

以真实场景检查为准：明暗主题切换保留输入、实际圆角/合成泛光、同宽及连续开关不重叠、歌词初次加载/暂停/换曲/重开/单行降级、旧启动项修复与关闭、SQLite WAL 快照和两个包的数据隔离。屏外模板或算法检查不能代替实际播放器、Explorer、多 DPI 与下次登录验收。具体执行结果见交付时验证记录。
