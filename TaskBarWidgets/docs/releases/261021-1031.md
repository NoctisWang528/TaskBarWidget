# TaskBarWidgets 261021-1031

Windows 11 x64。天气卡预报温度条改为按温度连续渐变着色。

- 每日温度条使用固定绝对温度色阶，在当天最低温与最高温之间水平渐变；同一温度始终对应同一颜色。
- 色阶范围为 `-20°C` 至 `40°C`，超出范围时使用两端颜色；最低温等于最高温时显示纯色，缺少温度时只保留中性轨道。
- 温度条原有位置、长度、尺寸、圆角和卡片布局保持不变，浅色与深色主题使用相同的温度色阶。

升级前请退出旧版并备份配置、流量历史和媒体数据。更新会保留已有数据；首次启动使用默认设置。

运行需要 Windows 11 x64、.NET 8 Desktop Runtime x64 最新 8.0 补丁、Windows App Runtime 2.5.1 x64 或兼容的更新 2.x、Microsoft Edge WebView2 Runtime 和管理员权限。
