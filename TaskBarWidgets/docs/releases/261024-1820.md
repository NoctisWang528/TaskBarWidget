# TaskBarWidgets 261024-1820

Windows 11 x64。改进和风天气连接提示，并支持新版空气质量数据。

## 用户可见变更

- 天气连接错误提供更清晰的原因，包括域名解析、连接、超时、安全连接、凭据、访问权限与账户额度问题；共享故障不再重复请求并堆叠相同报错。
- 空气质量改用新版数据接口，显示 AQI 及对应标准，保留污染物浓度、单位和数据来源说明。
- 空气质量或预警获取失败时显示独立提示，保留同一地点的上次数据并说明可能过时；成功更新后清除旧错误。
- 修复实况更新成功后，预报阶段的共享连接或账户故障可能被掩盖为整体成功的问题。

## 升级注意事项

和风天气请使用账户控制台 → 设置 → API Host 提供的完整专属地址，按原样填写，不要自行替换域名后缀。API Key 使用同一账户的凭据；留空会保留已有密钥。保存并验证连接后，再选择城市保存，或点击“切换来源并刷新”。服务可用性仍取决于正确的 Host、有效凭据、接口权限及账户额度。

升级保留已有城市、设置、天气凭据和历史，无需删除配置。没有生效预警时不显示预警内容；预警范围以服务对选定位置返回的内容为准。

## 运行要求

需要 Windows 11 x64、.NET 8 Desktop Runtime x64 最新 8.0 补丁、Windows App Runtime 2.5.1 x64 或兼容的更新 2.x，以及管理员权限。完整解压后运行 `TaskBarWidgets.exe`，不要单独启动 Media/UI 内的辅助程序。

## 附件与数据

提供完整 ZIP、`SHA256SUMS.txt` 和 `update.json`。发行包不包含个人配置、天气凭据、历史、数据库、日志或截图，保留第三方许可证；更新保留已有个人数据，升级前仍建议备份。
