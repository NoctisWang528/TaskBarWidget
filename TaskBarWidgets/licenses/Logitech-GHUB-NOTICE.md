# Logitech G HUB brand artwork

The Logitech mark in `Native/Cards/BrandLogos.h` is a monochrome vector redraw of the white G mark in the locally installed Logitech G HUB system tray executable's Windows icon resource. It replaces the former Simple Icons Logitech / Logi wordmark.

- Source executable: `%ProgramFiles%/LGHUB/system_tray/lghub_system_tray.exe`
- File version: `2026.7.1011216`
- Executable SHA-256: `d5a150db14204b30c0217e7f6457cbd6849f30d99d54e7429656a24cfa77dab1`
- Resource group: `IDI_ICON1`; `RT_ICON` ID `1`, 256 x 256, 32-bit DIB.
- Raw RT_ICON SHA-256: `743180184d0ebcc498f112c36845909496a1048793ba392294ef4660acfa9a08`
- Extraction date: 2026-11-10. The executable was opened as a data/image-resource file only; it was not executed or modified.

The redraw preserves the source mark's semicircular band and right-angle arm proportions using clean SVG arcs and straight edges. It omits the dark application-icon disc, raster antialiasing and padding, centers the mark in a 24 x 24 viewBox, and uses the existing theme foreground color and 16-DIP brand slot. The source executable, icon resources and PNG inspection copies are not shipped or required at build/runtime.
