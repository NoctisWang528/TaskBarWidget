# 界面与交互规范

更新：2026-10-24。可见设置采用 WinUI3（按需启动、关闭后退出）；四张快捷卡片迁入原生主进程，使用 C++/WinRT＋Direct2D／DirectWrite＋Composition 绘制。本文覆盖历史 WPF／网页设置方案。

设置主导航为任务栏与布局、硬件与网络、播放源、歌词、常规、关于。歌词作为一个可展开分类，包含显示与行为、布局与样式、歌词匹配、单曲偏移、诊断与维护；保留原页面路径以兼容已有入口。音频设置页与全局快捷键功能删除，不注册全局键盘组合。

媒体来源选择使用至少34 DIP高的按钮，显示20 DIP应用图标、名称和下拉标识；列表项目至少44 DIP高，显示对应应用图标并标注当前来源。长名称省略，图标不可用时使用通用符号，异步图标加载不能阻塞播放控制或把旧图标写到新来源上。

## 任务栏

监测与媒体共用一个非分层窗口，由 DirectComposition 切换表面。原生窗口接收输入：左键打开面板、右键打开应用菜单、滚轮切换模式。浏览器媒体按钮可独立操作，任务栏不显示悬停详情。

字体、背景色和不透明度共用一套配置，集中在任务栏设置中；媒体样式更新不能覆盖它们。显示模式切换有约180ms淡入淡出，并遵守系统减少动画与高对比度设置。

## 模块编辑

页面依次包含示例预览、组合条、模块池和通用布局／外观设置。

- “水平单行排列”位于组合条旁，开启时一条，关闭时上／下两条。
- 模块默认仅显示名称等摘要；单击打开右侧属性抽屉。
- 从池拖入启用，条内或跨条移动调整位置，拖回池移除但保留属性。
- 使用窗口内指针捕获完成拖动，提供目标强调、取消和键盘操作，不使用系统 OLE 拖放。
- 模块显示、顺序及行号整体提交；保存回读不覆盖期间新增的编辑。
- 稳定 ID 对应 `item_order_ids` 和 `item_rows`。旧版导入布局保持兼容，首次编辑组合后使用明确的独立行。
- 双行组合保留每行顺序，但上下对应位置共用列宽，取两项所需宽度的较大值；项目间距作用于列之间，不能各行独立累加造成错位。单侧剩余项目保留所在半行；明确要求双行独占的项目单独占满一列。设置预览遵循同一列规则。

## 快捷卡片

普通卡片为天气、流量、音频设备、媒体，默认顺序可由“快捷卡片”拖动调整；天气卡默认位于顶部，升级用户首次加载时保持关闭。普通卡片设计宽度384DIP，卡片间距12DIP；工作区不足时统一适配。更新就绪时，媒体右侧的独立第二列显示约220DIP宽更新提示卡并与主列底部对齐；更新卡不参与普通卡排序。尺寸与整组定位由原生 `CardHost` 唯一管理，内容动画只移动合成视觉，不改变窗口位置。没有共同外框和卡片关闭按钮，实际外部点击、Esc、再次点击入口或进入设置时收起。仅焦点变化不得收起；鼠标监听仅在卡片显示时存在，不拦截其他应用的输入。

流量卡片完整显示最近12周，格子保持正方形，不设滚动条。每日上传加下载合计着色，区分未知／零／未来。按用户确认，正流量依据这12周日峰值的25%、50%、75%分成四档，图例注明相对范围和峰值；未来日期与窗口外记录不参与峰值。采用 token-monitor 风格的蓝色色阶和同色柔光，在选中、焦点和悬停时强调，高对比度下退化。日期详情可点击保持，也可在格子提示中查看；原始流量统计不改变。

输入、输出各显示当前设备、音量及静音；设备选择用浮动列表，列表不改变卡片宽高。自有浮动窗口属于卡片组，不因其焦点切换而收起整个面板。快捷面板和同步通信设备固定启用，不再设置音频偏好页。

音频操作即时显示处理状态，只锁定对应的输入或输出区域。直接应用操作回复中的设备读回结果，拒绝迟到旧状态；静音不附带音量写入。输入输出设备订阅复用，音频命令不等待流量历史或设置请求。

媒体卡片提供封面、曲目信息、来源切换、进度与播放控制；右上角设置按钮进入统一设置。

卡片圆形控制图标使用 `Native/Cards/CardIcons.cpp` 的矢量路径（上一首、播放／暂停、下一首、扬声器、扬声器静音、麦克风、麦克风静音、设置、刷新），不依赖 Segoe Fluent Icons；图标位于固定 20 DIP 宿主并居中，静音状态只切换矢量图形。

## 设置与动效

采用原生 NavigationView、SplitView抽屉、菜单、ColorPicker和NumberBox。主导航“快捷卡片”下含“卡片与顺序”“天气”，四张普通卡均可启停、排序；所有设置统一通过“应用更改”保存，关闭窗口或重新读取时保护未保存草稿。次要复选框保留原生模板内边距，最小高度32DIP，不为单个布尔项留大块空白。使用Mica及原生主题资源；动画遵守系统偏好。界面主题在所有快捷卡片中同步预览（包括弹出菜单和更新提示卡），应用后保存、重新读取可撤销；后台旧状态不得覆盖预览。任务栏自定义配色保持独立。

“单曲偏移”页采用显式进入生命周期：每次进入只激活并查询一次；搜索、刷新、翻页只查询；响应按单调递增 `requestId` 和页面代次校验，过期响应整批丢弃，每次有效批次只渲染一次。

所有可见界面位于 `UI/`。`Media/` 中旧设置类仅作为未显示的功能适配器，不能作为第二个设置界面重新开放。关于页链接到个人项目并保留来源说明。

天气使用专用设置卡片，替代城市名称／代码两个自由文本框：来源下拉、城市搜索、带区域和代码的结果选择、只读代码、保存并刷新、立即刷新、状态与成功时间。切换来源或更改搜索文本会丢弃迟到结果。和风连接配置只在该来源下展开，API Key 为密码框且只写不读；已有密钥只显示是否存在，留空保留，清除需显式操作。城市／连接即时保存与全局“应用更改”互斥，避免配置覆盖；配置没有读取成功时仍保留天气入口并显示错误。

## 验证边界

天气悬停提示不再属于产品界面；任务栏温度显示项与天气卡相互独立。天气代码由原生层映射为稳定的 `conditionKind`，卡片只使用提供方中立字段。天气卡固定采用 Apple 风格横向双栏布局，不设置独立“天气”标题；左栏显示城市、紧邻的刷新按钮、当前温度和天气状态，右栏显示最多五行预报。没有城市或来源未返回完整数据时，卡片正文替换为空状态：说明文字下始终提供与左栏相同的刷新按钮，没有城市时同时保留“打开天气设置”；刷新进度与失败结果回显在该空状态内，不留下无动作可点的提示。内容直接置于卡片窗口的 Mica 背景中，不叠加内部圆角框，也不再使用蓝色渐变天空。左下角预警区在无预警时留空、单条时固定显示、多条时每 4 秒轮换显示一条；天气图标为 `Native/Cards/CardIcons.cpp` 中按 128×128 设计空间绘制的分层彩色矢量（云体 + 云影 + 太阳/月亮/降水），浅色与深色主题各有一套调色板，并在主题切换时重绘；大图标 42 DIP、预报行 28 DIP。温度文本按列宽自适应字号（48→26 DIP），与图标之间始终保留 6 DIP 间距，不得压住度数符号。快捷卡片共用可在“快捷卡片 → 卡片与顺序”设置的卡片字体；材质区域提供“自定义 Mica”开关（默认开启），浅色、深色分别提供“中性色遮罩”“明暗调和”两个滑块（共四个，范围 0–100%），直接对应 `TintOpacity`、`LuminosityOpacity`；不将亮度调和解释为透明度或饱和度。默认原始数值保持浅色 0.10／0.85、深色 0.15／0.90，界面显示 10%／85%、15%／90%；已有配置不因改名而改写。界面明确当前预览主题、另一主题的预览方式及系统纯色回退状态。中性色遮罩越高，浅／深色覆盖越强，降低通常更能保留壁纸颜色；Mica 来自壁纸，不透出后方窗口。

设置窗口与原生快捷卡片使用相同的材质参数语义（原生卡片由 Native/Cards/CardWindow.cpp 的 MicaController 承载），窗口存活期间不交换 backdrop 对象。自定义浅色使用 `MicaKind.Base`、中性 `#F3F3F3`，深色使用 `MicaKind.BaseAlt`、中性 `#202020`；关闭自定义时使用 `Base` 与 `ResetProperties()` 恢复系统默认，不再用固定数值模拟。快捷卡片保持材质输入活跃，设置窗口遵守正常焦点行为，失焦或系统策略回退需明确区分。整个设置窗口取消 NavigationView 的重复内容底色，普通设置分组与卡片共用 `#0AFFFFFF` 轻薄覆盖层，控件、抽屉及菜单保持可读，高对比度采用系统不透明色。

“开关＋四个参数”作为完整外观状态分为已提交值和草稿预览。打开设置会隐藏快捷卡片；设置背景预览当前主题，之后打开／新建卡片和更新卡继承完整草稿，后台旧值不得覆盖预览开关或数值。只有应用成功并读回才更新已提交值；离页／关闭恢复已提交值，返回材质页继续预览未保存草稿。合法 0／1 端点必须保存后稳定读回，仅缺少字段时做兼容迁移。材质恢复后重新应用保留参数；视觉调校通过隔离窗口在同一壁纸位置逐组捕获系统默认、现有默认以及遮罩 0／明暗调和 85、65、45 的实屏对比，回退状态不算视觉通过，不改个人配置或出厂默认。

2026-10-21 用户认可当前 Mica 观感，本轮视觉调校收尾；保留当前实现、个人参数和出厂默认，不将实屏对比候选自动设为默认。跨显示器、混合 DPI 和系统辅助功能切换仍按各自场景验收。

四张普通卡全部关闭时，任务栏入口无响应，设置保存前会再次确认。

预报温度条采用固定绝对温度色阶：同一温度始终对应同一颜色，每日填充在自身最低温到最高温之间水平渐变；`-20°C` 以下与 `40°C` 以上分别钳制到色阶两端，最低温等于最高温时使用纯色，缺少任一端时只显示中性轨道。

对重复打开、宽度、DPI、浮动列表焦点、连续拖动／保存分别验收。隐藏控件零尺寸不算布局通过。发布资源检查与屏幕外模板自检必须针对最终发布包；Mica、手感和实际桌面交互由用户验收。
