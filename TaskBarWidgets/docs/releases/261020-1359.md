# TaskBarWidgets 261020-1359

Windows 11 x64。修复天气卡 QWeather 图标在部分系统上显示为方框的问题。

- 天气图标不再通过私有区字体字形渲染，改用 QWeather Icons 字体轮廓生成的独立矢量路径，避开实际合成路径中的字体回退与缺字方框。
- 当前天气和五天预报继续使用原有的 15 个天气状态映射，包括晴、多云、阴、雨、雪、雾、霾、沙尘、雷暴和风。
- 矢量路径按 28/42 DIP 的目标图标尺寸缩放并保留 2 DIP 内边距，修复 `PathIcon` 按原始字体坐标裁切导致的空白图标；浅色和深色主题继续自动继承文字前景色。
