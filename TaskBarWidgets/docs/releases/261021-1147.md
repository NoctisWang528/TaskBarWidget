# TaskBarWidgets 261021-1147

Windows 11 x64。修复旧版下载更新后误报“Personal data cannot be included in updates”的问题，并包含本轮 Mica 调节与预览改进。

- Mica 设置资源使用旧版更新器兼容的程序路径，个人数据保护规则保持不变。
- “自定义 Mica”提供浅色、深色各两项“中性色遮罩”“明暗调和”，设置页减轻重复底色，设置窗口与卡片使用一致的真实材质实现。
- 修复未保存的材质开关被旧状态覆盖，以及合法参数端点在重启后被重置的问题。
- 保留现有个人参数和出厂默认值。

若上一版仅在下载完成后报错，重新检查更新并下载本版即可，无需删除个人配置或流量历史。错误的 261021-1120 Release 已撤回，Git 标签与源码历史保留；请使用本版。此前没有应用更新功能的老版本仍需手动下载完整 ZIP。

## 运行与附件

需要 Windows 11 x64、.NET 8 Desktop Runtime x64 最新 8.0 补丁、Windows App Runtime 2.5.1 x64 或兼容的更新 2.x、Microsoft Edge WebView2 Runtime 和管理员权限。完整解压后运行 TaskBarWidgets.exe，不要单独启动 Media/UI 内的辅助程序。

提供完整 ZIP、SHA256SUMS.txt 和 update.json。发行包不包含个人配置、天气凭据、历史、数据库、日志或截图，保留第三方许可证；更新保留已有个人数据。
