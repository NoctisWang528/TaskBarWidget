# TaskBarWidgets 261018-1213

Windows 11 x64，合并两轮卡片交互和设置改进。

- 统一任务栏点击手势，修复媒体模式入口失效及重复切换路径。
- 媒体卡片新增同步歌词，沿用任务栏字体与动画，空间不足时显示单行。
- 完善设置深浅主题、热力图圆角泛光和设备卡片自适应高度。
- 登录自启改用当前用户的交互式最高权限计划任务，并提供状态与修复入口。
- 歌词相关设置归入一个分类；移除音频偏好和全局快捷键，快捷面板与默认通信设备同步固定开启。
- 媒体来源选择增加应用图标、更大的点击区域及当前来源标记。
- 便携模式的媒体设置、歌词映射和偏移随包存放于 `Data/`。

升级前退出旧版并备份配置与历史，按[迁移说明](https://github.com/NoctisWang528/TaskBarWidget/blob/261018-1213/TaskBarWidgets/README.md#日用迁移)搬迁旧媒体数据。新目录使用后，可在“设置 → 常规”点击“修复并启用登录启动”。

附件为干净 ZIP 和 SHA256 校验文件，不含个人配置、天气凭据、流量历史或歌词数据库。完整解压后运行根目录 `TaskBarWidgets.exe`；需要管理员权限和 Edge WebView2 Runtime，第三方许可随包保留。

完整构建、定向回归、屏外控件及最终包检查通过；真实播放器动效、多源切换、混合 DPI 和下次登录等桌面场景仍需验收，详见[验证记录](https://github.com/NoctisWang528/TaskBarWidget/blob/261018-1213/TaskBarWidgets/ACCEPTANCE.md)。
