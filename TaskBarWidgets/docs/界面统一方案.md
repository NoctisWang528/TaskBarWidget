# 界面与交互规范

更新：2026-10-14。可见设置和卡片统一采用 WinUI3；本文覆盖历史 WPF／网页设置方案。

## 任务栏

监测与媒体共用一个非分层窗口，由 DirectComposition 切换表面。原生窗口接收输入：左键打开面板、右键打开应用菜单、滚轮切换模式。浏览器媒体按钮可独立操作，任务栏不显示悬停详情。

字体、背景色和不透明度共用一套配置，集中在任务栏设置中；媒体样式更新不能覆盖它们。显示模式切换有约180ms淡入淡出，并遵守系统减少动画与高对比度设置。

## 模块编辑

页面依次包含示例预览、组合条、模块池和通用布局／外观设置。

- “水平单行排列”位于组合条旁，开启时一条，关闭时上／下两条。
- 模块默认仅显示名称等摘要；单击打开右侧属性抽屉。
- 从池拖入启用，条内或跨条移动调整位置，拖回池移除但保留属性。
- 使用窗口内指针捕获完成拖动，提供目标强调、取消和键盘操作，不使用系统 OLE 拖放。
- 模块显示、顺序及行号整体提交；保存回读不覆盖期间新增的编辑。
- 稳定 ID 对应 `item_order_ids` 和 `item_rows`。旧版导入布局保持兼容，首次编辑组合后使用明确的独立行。

## 快捷卡片

三个独立窗口从上到下为流量、音频设备、媒体。设计宽度384DIP，卡片间距12DIP；工作区不足时统一适配。尺寸由 AppWindow 管理，内容动画不改变窗口位置。没有共同外框和卡片关闭按钮，外部点击或Esc收起。

流量卡片完整显示最近12周，格子保持正方形，不设滚动条。每日上传加下载合计着色，区分未知／零／未来；同色泛光在选中、焦点和悬停时强调，高对比度下退化。日期详情通过点击呈现。

输入、输出各显示当前设备、音量及静音；设备选择用浮动列表，卡片宽高保持不变。自有浮动窗口属于卡片组，不因其焦点切换而收起整个面板。同步通信设备偏好只放在音频设置。

媒体卡片提供封面、曲目信息、来源切换、进度与播放控制；右上角设置按钮进入统一设置。

## 设置与动效

采用原生 NavigationView、SplitView抽屉、菜单、ColorPicker和NumberBox。次要复选框约30DIP高，不为单个布尔项留大块空白。使用Mica及原生主题资源；动画遵守系统偏好。

所有可见界面位于 `UI/`。`Media/` 中旧设置类仅作为未显示的功能适配器，不能作为第二个设置界面重新开放。关于页链接到个人项目并保留来源说明。

## 验证边界

对重复打开、宽度、DPI、浮动列表焦点、连续拖动／保存分别验收。隐藏控件零尺寸不算布局通过。发布资源检查与屏幕外模板自检必须针对最终发布包；Mica、手感和实际桌面交互由用户验收。
