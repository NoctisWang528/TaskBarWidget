# TaskBarWidgets 261022-0013

Windows 11 x64。修复任务栏在缩放或 DPI 变化后反复出现 Direct2D/DirectComposition 错误的问题。

- 设备重建前先解除旧绘图上下文对任务栏交换链目标的引用。
- 交换链无法原地调整时自动重建，避免每帧重复失败并持续写日志。
- 保留现有个人配置、流量历史和设置。

## 升级说明

若 261021-2224 出现过任务栏刷新异常或 `error.log` 持续记录 `0x887A0001`，升级到本版后无需删除配置或历史。更新器会先正常退出现有进程，再替换受管程序文件并重新启动。

## 运行与附件

需要 Windows 11 x64、.NET 8 Desktop Runtime x64 最新 8.0 补丁、Windows App Runtime 2.5.1 x64 或兼容的更新 2.x，以及管理员权限。完整解压后运行 TaskBarWidgets.exe，不要单独启动 Media/UI 内的辅助程序。

提供完整 ZIP、SHA256SUMS.txt 和 update.json。发行包不包含个人配置、天气凭据、历史、数据库、日志或截图，保留第三方许可证；更新保留已有个人数据。
