# TaskBarWidgets 261022-1102

Windows 11 x64。修复"背景透明"与任务栏背景色设置的保存和显示问题。

- 勾选"背景透明"后，设置不再因为保存请求超时被丢弃，重启后仍然透明。
- 开启 Direct2D 渲染时自动开启的"背景透明"现在会写入配置，不再只在当次运行生效。
- 背景透明开启后，不再自动把桌面采样颜色写回任务栏背景色，配合第三方任务栏透明工具时不会重新出现实色背景块。
- 背景透明开启后，不再回退到按任务栏颜色着色的不透明渲染路径。

## 升级说明

本版不改动配置项名称和含义，升级后无需删除配置，已有的背景色、透明与渲染设置保持原样。如果升级前"背景透明"没有生效，重新勾选一次并保存即可写入。

## 运行与附件

需要 Windows 11 x64、.NET 8 Desktop Runtime x64 最新 8.0 补丁、Windows App Runtime 2.5.1 x64 或兼容的更新 2.x，以及管理员权限。完整解压后运行 TaskBarWidgets.exe，不要单独启动 Media/UI 内的辅助程序。

提供完整 ZIP、SHA256SUMS.txt 和 update.json。发行包不包含个人配置、天气凭据、历史、数据库、日志或截图，保留第三方许可证；更新保留已有个人数据。
