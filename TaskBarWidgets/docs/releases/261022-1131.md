# TaskBarWidgets 261022-1131

Windows 11 x64。修复保存设置后任务栏窗口停止刷新、后续保存被无限期阻塞的问题。

- 保存设置导致任务栏窗口重建后，新窗口能重新接收内部刷新通知。此前这条通知会随着旧窗口一起被丢弃，重建出的窗口不再刷新，第二次保存就一直等待到超时。
- 由此，勾选"背景透明"并保存后当次即可看到效果，不再需要重启程序才会透明。
- 窗口重建后媒体与设置请求继续被处理，不会出现界面卡在"保存中"的情况。
- 保留上一版的修复：保存请求的时间余量、背景透明时不再写回桌面采样色、背景透明时不再回退到不透明渲染路径。

## 升级说明

本版不改动配置项名称和含义，升级后无需删除配置，已有的背景色、透明与渲染设置保持原样。

## 运行与附件

需要 Windows 11 x64、.NET 8 Desktop Runtime x64 最新 8.0 补丁、Windows App Runtime 2.5.1 x64 或兼容的更新 2.x，以及管理员权限。完整解压后运行 TaskBarWidgets.exe，不要单独启动 Media/UI 内的辅助程序。

提供完整 ZIP、SHA256SUMS.txt 和 update.json。发行包不包含个人配置、天气凭据、历史、数据库、日志或截图，保留第三方许可证；更新保留已有个人数据。
