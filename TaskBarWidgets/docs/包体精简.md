# 包体精简与轻量分发

当前版本为 **261018-1408**，用户已接受并授权提交、推送和发布干净 ZIP。程序文件沿用验收构建，公开包在源码提交后重新生成来源清单。历史中间版本未单独发布。

| 261018-1213 | 208.2 MiB | 原始完整依赖 |

## 当前实现

- 不再分发完整思源黑体，使用系统字体。旧内置字体配置在未安装对应字体时回退；用户已安装字体仍可使用。
- 移除 WPF-UI 和不使用的 AI/ML/Search/Widgets/DirectML/ONNX 依赖；保留正在使用的 WPF/WinForms 后台、WinUI、SQLite 和硬件功能。
- Media/UI 使用系统 x64 .NET 8 Desktop/Core，采用 LatestPatch，允许兼容 8.0 补丁而不自动跨主版本。原生和媒体启动器仅为子进程选择共享运行库，不修改系统环境。
- WinUI 使用 Microsoft.WindowsAppRuntime.2 共享包，最低 2.5.1.0；保留小型 Bootstrap DLL、托管接口和应用 PRI/XBF。Runtime NuGet 提供版本常量与引导声明，不将运行库安装器/MSIX 放入 ZIP。
- 原生入口分别用 hostfxr 解析 Media/UI runtimeconfig，再用 MddBootstrapInitialize2 实际验证当前用户的 x64 WinUI 包；错误提示含原因、错误码和官方入口。用户点击按钮才打开下载页，不自动安装。
- 只分发简体中文与英文的语言文件/卫星资源。保留中立资源、框架 PRI 和全球化支持，不影响其他语言歌词、设备名及区域日期格式。
- 只分发实际使用的 Unicode MFC 和必要 VC 运行文件；许可证约占 ZIP 0.2 MiB，保留版权与分发声明。

## 环境要求

运行需要 .NET 8 Desktop Runtime x64、Windows App Runtime 2.5.1 x64 或兼容更新的 2.x；媒体与卡片为原生渲染，不需要 WebView2 Runtime。完整选择说明和微软下载链接见[README](../../README.md#下载与运行)。Windows 内置的 .NET Framework 4.x 不能代替 .NET 8；无需为运行本产品安装开发 SDK。

## 验证与数据

完整硬件版构建通过。隔离 Media/原生探针验证 Core/Desktop 来自系统共享目录，并覆盖缺失路径、不可用版本、损坏配置、缺失引导文件和 WinUI 版本不匹配；环境恢复和子进程选择一致。实际发布的 WinUI 探针确认设置/三张卡片使用系统 WindowsApps 中的 x64 WinUI，未激活窗口。

真实播放器、音频、管理员启动缺失依赖弹窗和混合 DPI 仍保留实机验收边界。测试不等于这些场景全部通过，详见[验收记录](../ACCEPTANCE.md)。

个人 build 与干净 release 分开生成。历史本地构建/临时文件清理前先校验路径、运行进程、文件占用，并备份配置、流量历史与歌词数据。当前运行目录、最新完整构建、个人数据备份与源码依赖保留；原始三个参考项目保持只读，远端历史 Release 不删除。
