# TaskBarWidgets 261019-1801

Windows 11 x64。新增“快捷卡片”设置分类、可选天气卡、按需后台资源和更新提示卡第二列。

- 四张普通卡片天气、流量、设备、媒体可独立启停、拖动排序；关闭卡片释放其窗口和歌词/图像重资源，重新启用时重建。
- “快捷卡片 → 天气”集中管理城市、来源、和风 API Host/Key、天气模块和减少动画；任务栏温度显示项保留，悬停天气提示及旧配置项移除。
- 天气卡使用结构化天气快照和中性天气状态，显示当前天气、三日预报、湿度、风、空气质量、降水、更新时间和预警；数据缺失的模块隐藏，预警在最多 140 DIP 区域滚动。
- 资源模式默认“常驻”，保留歌词 WebView2 和图片缓存；按需模式在隐藏 10 分钟后释放，重新打开自动恢复。
- 更新提示卡在更新就绪时显示为普通卡片右侧约 220 DIP 的第二列，不参与普通卡片排序。
- 设置关闭和重新读取会保护未保存草稿，全部关闭普通卡片时任务栏入口无响应并显示警告。
