# TaskBarWidgets 261024-1903

Windows 11 x64。修复天气设置的统一保存，优化天气卡片的数据来源显示。

## 用户可见变更

- 修改天气来源、选择城市或编辑连接配置后，顶部会显示待应用状态，并可通过“应用更改”统一保存；连接验证失败保留输入，便于修改重试。
- 保存普通设置时保留天气页面状态，撤销天气编辑后正确清除待保存提示。
- 天气卡片底部不再显示整条归因网址，改为简洁的“和风天气 · 数据来源”链接，保留其他来源说明。
- 改进和风天气连接错误提示，共享连接故障停止后续请求，避免重复报错。
- 空气质量使用新版接口，显示 AQI 及对应标准；空气质量或预警获取失败时显示独立提示，并标明保留数据可能过时。

## 升级与运行

升级保留已有城市、设置、天气凭据和历史，无需删除配置。和风天气连接使用账户控制台提供的完整 API Host 和 API Key；密钥留空保留已有值。

需要 Windows 11 x64、.NET 8 Desktop Runtime x64 最新 8.0 补丁、Windows App Runtime 2.5.1 x64 或兼容的更新 2.x，以及管理员权限。完整解压后运行 `TaskBarWidgets.exe`。

提供完整 ZIP、`SHA256SUMS.txt` 和 `update.json`，不包含个人配置、凭据或历史，保留第三方许可证。
