## 用户可见变更

- 新增任务栏双击动作，可打开任务管理器、运行（Win+R）或指定应用程序，在“设置 → 任务栏 → 任务栏双击”中配置。
- 启用双击时，单双击判定窗口最多为 250 毫秒，兼顾卡片单击响应与双击操作；系统设置更短时沿用更短值。关闭双击后，单击即时响应。
- 普通设置更改后自动保存；初次进入、窗口激活和重连时自动读取，不再需要手动保存或重新读取。
- 设置读回只更新变化的控件或局部列表，保留页面、滚动位置、属性抽屉及正在编辑的新内容；保存失败时保留更改并提供重试。
- 天气城市选择和兼容来源切换自动保存；连接验证和密钥清除仍保留明确的操作入口。
- 音频频谱设置简化为“柔和、均衡、动感”三个效果预设，隐藏采样、频段、增益和平滑等细节参数，保留显示策略和系统音频授权。

## 升级注意事项

应用内更新保留现有配置和历史数据。已有频谱自定义参数会显示为“当前配置”，主动选择预设后才替换。

双击动作可随时关闭；启用后需在判定窗口内完成两次点击，超过窗口按两次单击处理。此设置不会修改 Windows 全局双击速度。

天气 API Host 与密钥仍需通过“保存并验证连接”提交；密钥留空保留原值。

## 运行要求

Windows 11 x64；.NET 8 Desktop Runtime x64（建议安装最新 8.0 补丁）；Windows App Runtime 2.5.1 x64 或兼容的更新 2.x。
